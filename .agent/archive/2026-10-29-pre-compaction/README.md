# Pre-compaction continuity archive — 2026-10-29

`QKB.md` and `HANDOFF.md` are byte-for-byte snapshots taken before compaction.
`manifest.json` records their original byte/line counts and SHA-256 hashes.
These files contain historical, sometimes superseded instructions and diagnoses.
Use ../../HANDOFF.md, ../../QKB.md, current AGENTS.md and TODO.md first.
Search the archive when detailed evidence or an older issue is needed. The
`#L<number>` fragments in the QKB index are source-line hints; local Markdown
viewers may require opening the file and navigating to that line manually.
